How the math works
①
For each byte of your message, build a random polynomial of degree K-1 where the constant term = the secret byte
f(x) = secret + a₁x + a₂x² + ... + a₍ₖ₋₁₎x^(k-1)
②
Evaluate the polynomial at x=1, 2, ..., N to get N share values
Share i = (i, f(i))
③
All arithmetic is done in GF(256) — the same finite field used in AES encryption
④
Each share is LSB-encoded into a unique AI-generated image
★
Security guarantee: Any K-1 or fewer shares give zero information about the secret — proven by information theory

Reconstructed secret
Lagrange Interpolation
①
Given K points (x₁,y₁), ..., (xₖ,yₖ) from K share images
②
Reconstruct f(0) — the original secret byte — using:
f(0) = Σ yᵢ · Π (xⱼ / (xᵢ ⊕ xⱼ))
③
All operations (×, ÷, +) are done in GF(256) — division uses Fermat's little theorem: a⁻¹ = a²⁵⁴
④
Repeat for every byte of the message to recover the full secret
★
K-1 shares = zero info: for any possible secret value, there exists a valid polynomial passing through K-1 points — making them cryptographically useless alone

How it works

01
LSB steganography

The last bit of each pixel's Red, Green, and Blue channel is replaced with one bit of your message. The change is invisible — human eyes can't detect a 1-bit difference in color.

02
XOR encryption

If you set a password, the message is XOR-ciphered against it before embedding. Without the exact password, the decoded output will be garbled gibberish.

03
PNG output only

Always download as PNG. JPEG compression re-encodes pixels and destroys the hidden bits. PNG is lossless — every pixel value is preserved exactly.
